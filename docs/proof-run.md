# Проба вживую (Task 8)

Проверяет связку «ядро + движок» на настоящем сервере до того, как строятся служба и интерфейс.

## Запуск

```bash
make engine helper
scripts/proof.sh 'freeturn://…' 'https://…ссылка-на-звонок'
```

- Ссылка на звонок нужна только для Relay; для Direct второй аргумент не нужен.
- Если в ссылке нет конфига WireGuard, третьим аргументом передаётся файл `.conf`.
- Скрипт спросит пароль администратора: движку нужны права root, чтобы поднять utun.
- Ctrl-C останавливает туннель и возвращает сеть.

Итог пишется в `build/proof/result.txt` (каталог не попадает в git, в нём ключи).

## Что проверяется

| Проверка | Обязательна |
|---|---|
| Ядро подключилось | да |
| Движок поднял туннель | да |
| Трафик идёт через VPN (IP сменился) | да |
| Правило по домену уводит трафик напрямую | да |
| Правило по приложению уводит трафик напрямую | да |
| Сокеты ядра идут мимо туннеля (нет петли) | да |
| Ядро выходит по закрытию stdin | да |
| Интернет вернулся после остановки | да |
| AmneziaWG: рукопожатие проходит | нет, если нет сервера с Amnezia |

## Результаты

### 2026-11-14, macOS 26.6.2, Relay, WireGuard

| Проверка | Итог |
|---|---|
| Ядро подключилось | PASS (после ручной капчи в браузере) |
| Движок поднял туннель | PASS |
| Трафик идёт через VPN | PASS |
| Правило по домену уводит трафик напрямую | PASS |
| Правило по приложению уводит трафик напрямую | не проверено — сломана сама проверка |
| Сокеты ядра идут мимо туннеля | PASS: за 20 с ни одного переподключения |
| Ядро выходит по закрытию stdin | PASS |
| Интернет вернулся после остановки | PASS |
| AmneziaWG | не проверялось: сервер с обычным WireGuard |

Про правило по приложению. Проверка шла на копии `curl` по другому пути, а копию
платформенного бинарника Apple система убивает при запуске (код выхода 137), так что
запрос не ушёл вовсе. Сам движок процессы определяет: в его журнале видны пути Chrome,
`/usr/bin/curl`, VS Code и системных служб. Проверка переписана на `/usr/bin/nscurl`
и повторяется при следующем прогоне и на приёмке (Task 17).

Автоматическая капча в этом прогоне не прошла (`status=BOT` у старого решателя) —
ядро перешло на ручную. «Продвинутое» решение, как на Android, появится вместе с
приложением (Task 14).

Решение: архитектура подтверждена, работа продолжается.
