FreeTurn для macOS — чего не хватает по сравнению с Android-клиентом (5.3.4)
Сверено по исходникам Android-клиента и ядра v4.1.5. Порядок — по пользе.

ЭТАП 2. Доступ другим и бэкапы — [сделано в 0.2.0, кроме пользователей сервера]
1. Поделиться подключением
   - экран «Поделиться»: выбор сервера, имя пользователя, тип доступа (VPN WG/AWG или прокси);
   - ссылка freeturn:// + QR-код, кнопки «Копировать» / «Поделиться» (системное меню macOS);
   - опция «Вложить ссылку на звонок» (получателю не нужен свой аккаунт);
   - сборка ссылки как в ShareLinkBuilder: нормализация WG-конфига (без комментариев и MTU), Go-порядок полей.
   Требует SSH к серверу (client-add / client-conf) — см. этап 3; без SSH — только «поделиться своим конфигом».
   [сделано] «Поделиться» своим сервером: ссылка + QR, опции «ссылка на звонок» и «конфиг WireGuard», копировать/поделиться/сохранить QR.
2. Пользователи сервера — [перенесено в этап 3: нужен SSH к серверу]
   - список из client-list: имя, Client ID, WG-адрес, «был в сети N назад» (last handshake), «это устройство»;
   - «Показать ссылку» повторно, «Отозвать доступ» с подтверждением.
3. Резервная копия
   - экспорт серверов, профилей маршрутов и настроек в файл, шифрование паролем
     (PBKDF2-SHA256 210 000 итераций + AES-256-GCM, конверт JSON — как BackupCrypto на Android);
   - восстановление с заменой текущих данных; совместимость файлов с Android в обе стороны
     (серверы в формате ServerJson уже совпадают; профили маршрутов — только macOS);
   - пункт «Восстановление» в меню добавления сервера.
   [сделано] формат Android v4 + поле macRouting с профилями маршрутов; проверено вектором PBKDF2.

ЭТАП 3. Свой сервер по SSH
4. Подключение к VPS: адрес, порт, пользователь, пароль или ключ PEM, пароль sudo;
   проверка ключа хоста (TOFU) с предупреждением при подмене; SSH-лог.
5. Установка сервера мастером: Docker или systemd; «FreeTurn WG» (свой ft-wg0, порт, подсеть)
   или «Мой VPN» (host:port); порт 56000–56999; профиль обфускации с генерацией ключа;
   шаги с прогрессом, повторный запуск безопасен; после установки — профиль и WG-конфиг владельца.
   Протокол: install.sh из релиза ядра, RPC proto 3 (probe, apply, stop, logs, client-*, uninstall).
6. Управление сервером: состояние, применить настройки, обновить, остановить, журнал сервера,
   загрузка локальной сборки ядра, «Удалить FreeTurn с сервера».
7. Синхронизация с сервером: смена обфускации/пейсинга на клиенте применяется и на сервере;
   «Перезапуск сервера при смене профиля».

МЕЛОЧИ ИЗ ANDROID, КОТОРЫЕ СТОИТ ПЕРЕНЕСТИ
8. Раздача туннеля в локальную сеть: SOCKS5 на 0.0.0.0 (порт, логин/пароль, UDP ASSOCIATE).
   На маке проще всего — вход socks в конфиге движка (правило Sanitize надо расширить осознанно).
9. Внешнее управление (аналог Tasker/ярлыков): команды Shortcuts (App Intents) «Подключить» / «Отключить»
   и URL freeturn://connect, freeturn://disconnect; по умолчанию выключено.
